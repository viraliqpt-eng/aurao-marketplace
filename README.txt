AURAØ™ Marketplace v2.0 — PREMIUM EXPERIENCE

1. Descompacta o ZIP.
2. No repositório GitHub viraliqpt-eng/aurao-marketplace, escolhe Add file > Upload files.
3. Carrega index.html e confirma a substituição do ficheiro existente.
4. Faz Commit changes na branch main.
5. Aguarda a atualização do GitHub Pages e atualiza a página (Ctrl+F5).
